# Баня у Виктории

Локальный прототип сайта аренды бани в Солигорске на Vue 3, TypeScript, Bootstrap и Vite.

Посетитель знакомится с Викторией, смотрит фотографии бани и спальни, условия, свободные даты и маршрут. Бронь оформляется по телефону; сайт не принимает онлайн-заявки. Количество гостей и часов меняются кнопками «−»/«+» или вводом числа. Для почасовой аренды выбираются дата и время начала. Для посуточной — даты заезда и выезда двумя нажатиями; наведение или фокус показывают предварительный период и стоимость. Количество суток рассчитывается автоматически по разнице дат (13–15 число — двое суток), отдельного счётчика суток нет. Начало сохраняется при переходе между месяцами. Цена рассчитывается как тариф за одного гостя × число гостей × срок аренды. Доступность проверяется на весь период совместно с почасовыми бронями и закрытыми датами; точное время посуточного заезда и выезда согласуется по телефону.

В кабинете Виктория ведёт клиентов и календарь, вручную добавляет и отменяет брони, закрывает даты, меняет тарифы, загружает свой портрет, главное фото бани и фотографии галереи. На каждом дне многодневного проживания отображается бронь. Изменения сразу видны на главной в той же вкладке.

Карточки аренды и быстрые тарифы на главной открывают календарь с выбранным форматом. Галерея разделена на «Баня» и «Спальня» по формату аренды, связанному с фото; увеличенные снимки переключаются кнопками и стрелками клавиатуры. После выбора дат можно скопировать сводку для звонка; мобильная кнопка связи использует те же детали. Реальный телефон открывает приложение звонков, а скопированный текст остаётся подсказкой гостю.

Публичная страница оформлена в тёмно-фиолетовой палитре с розовыми акцентами. Световые потоки фона плавно движутся и меняют оттенок при прокрутке между разделами. Анимация работает на CSS без дополнительных библиотек, учитывает уменьшение движения в настройках устройства и приостанавливается в скрытой вкладке. Основной текст формы — 16 px и больше, вспомогательные подписи — от 14 px. Сброс дат оформлен отдельной кнопкой; сводка для звонка — выделяемая текстовая карточка без изменения размера.

## Запуск

Node.js 22.18+ или 24+.

```sh
npm ci
npm run dev
```

Сайт бани открывается на **http://127.0.0.1:5184/**. Порт закреплён: если он занят, запуск остановится с понятной ошибкой и не перейдёт на другой адрес. Для `npm run preview` используется порт 4184.

В PhpStorm выберите конфигурацию запуска **«Баня у Виктории»**: она привязана к `package.json` текущего проекта. После копирования проекта закройте старую вкладку терминала и откройте новую — уже запущенный терминал может оставаться в папке исходного проекта. Если папка терминала неизвестна, запустите явно:

```sh
npm --prefix C:\Users\vovch\Desktop\arendaBanya run dev
```

`npm test` — проверки модели; `npm run build` — TypeScript и production-сборка.

## Тестовые данные

- Телефон: +375 (00) 000-00-00, намеренно не подключён к звонкам. Заменить `label`, `href` (tel:...) и `isDemo` в `src/entities/specialist/config/contacts.ts`.
- Тестовый адрес: Беларусь, Солигорск, проспект Мира, 32Б. Конфигурация карты и маршрута — `src/entities/specialist/config/location.ts`.
- Галерея содержит 20 демонстрационных фотографий Pexels: сауны, интерьеры, экстерьеры и спальня. Это примеры оформления, не фотографии бани Виктории. Авторы, страницы и лицензия — `public/images/bathhouse/SOURCES.md`. В галерее основное фото не дублируется.
- Главный демо-портрет сохранён в `public/images/demo/host-portrait.png`: прежний вымышленный образ на домашней веранде, созданный встроенным Imagegen. Промпт — `public/images/demo/host-portrait.prompt.txt`. Портрет показан целиком в прямоугольной рамке с декоративной подложкой. Заменить портрет/главное фото можно в «Фото сайта», остальные снимки — в «Галерея бани».
- Тестовые ставки: 20 BYN за гостя в час и 80 BYN за гостя в сутки со спальней. Например, 4 гостя на 3 часа — 240 BYN; 3 гостя на 2 суток — 480 BYN. Тарифы меняются в кабинете; в существующих бронях сохраняются количество гостей, исходный тариф и итоговая цена. Цена 0 отображается как «По согласованию», копейки не теряются при расчёте.
- Для ввода количества гостей установлен технический предел 1–30. Это не заявленная вместимость бани или спальни; реальные ограничения ещё нужно уточнить.
- Тестовые часы начала аренды 10:00–19:00, шаг 30 минут; часовая аренда заканчивается до 19:00. Посуточная длится выбранное число полных 24-часовых периодов со временем начала, указанным в брони. Часовой пояс — Беларусь (UTC+3), горизонт 90 дней. Финальные часы и правила заезда/выезда требуют уточнения.

## Ограничения прототипа

Кабинет открывается без авторизации. Данные и загруженные фото находятся в памяти вкладки и исчезают после обновления. База данных, защищённый вход, загрузка на сервер и синхронизация между посетителями ещё не подключены. Публичный календарь сейчас демонстрирует работу общей модели в одной вкладке; для реальной работы требуется сервер.

Проект работает локально. Привязка к хостингу исходного проекта удалена; публикация этого сайта не выполнялась.
