# Ольга — косметология

Прототип на Vue 3 и Vite. Демонстрационные процедуры и цены; записи находятся в оперативной памяти браузера и исчезают при перезагрузке. Напоминания не отправляются. Не вводите реальные контактные данные.

## Запуск

```sh
npm install
npm run dev
```

Сборка: `npm run build`.

## Рабочая версия

Для Vue рекомендуется Nuxt с серверным API. Next.js использует React и не нужен одновременно с Vue. Перед запуском: согласовать процедуры, цены, длительность, рабочие часы, часовой пояс, фотографии и контакты; добавить базу данных, защищённый кабинет, серверную проверку пересечений, согласие на обработку персональных данных и очередь напоминаний с выбранным провайдером SMS или Telegram. Демо-кабинет не является защищённым кабинетом.
